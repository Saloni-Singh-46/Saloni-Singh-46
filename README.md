# 🔥 Featured Projects

## 🧠 NexusRAG — Multi-Modal RAG System

**Python • FastAPI • React • LLMs • Hybrid Search**

An end-to-end Retrieval-Augmented Generation system designed for working with
documents and codebases.

### Highlights

- 🔎 Hybrid retrieval using dense vector search + BM25
- 🔀 Reciprocal Rank Fusion for combining search results
- 🎯 Cross-encoder re-ranking
- 🌳 AST-based code chunking
- 💬 Conversational query rewriting
- 🛡️ Hallucination verification guardrail
- 🔄 Multi-provider LLM routing
- 🚀 Production deployment using Render
- 📈 Achieved **0.93 Precision@1** on a 30-pair evaluation benchmark

👉 [View Repository](https://github.com/Saloni-Singh-46/nexusrag)

## 🚗 LumiDrive / RoadSight — Road Perception Research

**Python • PyTorch • React • TypeScript • Computer Vision**

A multi-task deep learning project focused on road perception from monocular
video under challenging weather and driving conditions.

### Highlights

- 🛣️ Lane segmentation
- 🚘 Drivable-area segmentation
- 🧠 CSP-style backbone
- 🏗️ Feature Pyramid Network
- 🔄 ConvGRU temporal aggregation
- 🎯 Cross-task consistency loss
- 📊 Interactive React/TypeScript research dashboard
- 📄 IEEE-style research manuscript

👉 [View Repository](https://github.com/Saloni-Singh-46/LumiDrive)
