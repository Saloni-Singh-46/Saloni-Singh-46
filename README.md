# 🔥 Featured Projects

## 📈 FinSight — Multi-Agent Financial Research Platform

**Python • LangGraph • FastAPI • Streamlit • XGBoost • LightGBM • PyTorch • Docker**

An end-to-end multi-agent AI financial research platform designed to generate comprehensive equity research reports for Indian stocks.

### Highlights

- 🤖 Designed a stateful LangGraph workflow with **7 specialized AI agents**: Planner, Data, Quant, Sentiment, Filings-RAG, Critic and Writer.
- 🔄 Implemented critic-driven revision loops for consistency checking and citation verification.
- 📊 Developed XGBoost and LightGBM directional classification models.
- 🧠 Built a PyTorch LSTM quantile forecasting model for probabilistic price prediction.
- 🔍 Integrated SHAP-based model explanations, anomaly detection and systematic backtesting.
- 📚 Implemented hybrid BM25 + dense vector retrieval over annual report passages with page-level citations.
- 💬 Integrated financial sentiment analysis using FinBERT.
- ⚡ Developed FastAPI REST APIs with Server-Sent Events (SSE) for live agent execution traces.
- 📈 Built a multi-page Streamlit dashboard with interactive visualizations.
- 📄 Added PDF, HTML and Markdown research report exports.
- 🐳 Containerized the application using Docker and Docker Compose.

👉 **[View Repository](https://github.com/Saloni-Singh-46/FinSight)**
